# 集团总部及各分公司综合行政与财务管理制度（2026修订版）

## 第一章 考勤与休假管理
### 1.1 总部考勤规范
- 集团总部上班时间为早上 9:30，打卡截止时间为 9:45。9:45 后打卡视为迟到。
- 每月允许 2 次 15 分钟以内的无责迟到；超过 2 次后，每次迟到扣除绩效工资 50 元。
- 超过 10:30 未打卡且未请假者，按半天旷工处理。

### 1.2 北京分公司特殊考勤规范
- 北京分公司因交通原因，上班时间调整为早上 9:00，打卡截止时间为 9:15。
- 迟到 1 0分钟以内扣款 30 元，超过 30 分钟按旷工半天处理。

### 1.3 上海研发中心弹性工时制
- 上海研发中心实行核心工时制，核心在岗时间为 10:30 - 16:30，每日满足 8 小时工作制即可，免打卡。
- 实习生与外包人员不享受弹性工时，打卡截止时间统一为 10:00。

### 1.4 休假与带薪年假规则
- 入职满 1 年员工享受 5 天带薪年假，每增加 1 年工龄增加 1 天，上限 15 天。
- 病假需在复工后 48 小时内提交三甲医院诊断证明，病假期间按基本工资的 80% 发放。

## 第二章 差旅与餐补报销标准
### 2.1 差旅餐补标准
- 总部正式员工：单次差旅餐补上限为 150 元/人/天，需凭正规餐饮发票在每周五通过 OA 系统提交审核。
- 北京分公司员工：鉴于当地消费水平，单次差旅餐补上限为 200 元/人/天。
- 上海研发中心员工：餐补直接打入园区餐卡，每月固定发放 600 元，不接受发票单独报销。
- 实习生与试用期员工：差旅餐补上限为 80 元/人/天。

### 2.2 差旅住宿与交通标准
- 一线城市（北上广深）住宿标准上限为 500 元/晚，其余城市为 350 元/晚。
- 飞行时间超过 6 小时可申请商务舱，其余统一乘坐经济舱；高铁限二等座。

## 第三章 IT与研发规范
### 3.1 代码提交与 GitHub 规范
- 所有提交至公司 GitHub 仓库的 Commit Message 必须遵守 Conventional Commits 规范，例如使用 `feat:`, `fix:`, `docs:`, `refactor:` 等前缀。
- 严禁将任何 API Key、密码、私钥等敏感信息硬编码提交至代码库，一经发现取消当季绩效。
- 上海研发中心主干分支为 `main`，所有 Feature 必须经由 Pull Request 审查且通过至少 1 位 Senior 工程师 Approve 方可合并。
